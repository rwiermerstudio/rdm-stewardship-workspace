# Meridian learning role-play

This is a fictional teaching exercise, not an institutional review, consent process or repository service. Meridian's projects, people and candidate archives are invented.

## Learner route

Six cards name the discipline, researcher and situation before a choice. Each option includes a short reasoning cue; the consequence is shown only after selection, and a sound choice has a case-specific unresolved next step. The first workbench view hides the draft, copy labels, role controls and vocabulary. A risky choice alters the draft and event history without changing real files. Retry withdraws that proposal; the corrected choice writes a different private plan. Only then does the learner enter an invented method reference. The format rule rejects some obvious accidental entries, but cannot detect real names or locations. Never enter subject content.

The steward, privacy reviewer and, for oral history, community-appointed reviewer select a case-specific statement about the draft or missing evidence. These are training responses. They cannot attest to inspection, consent or permission. Description visibility and recording requests are separate decisions. Only a missing-evidence statement can return a question. The researcher chooses between a case-specific correction and a plausible inadequate shortcut; the latter explains the remaining gap without reopening review. A new invented reference is also required. The correction is a learning choice, **not proof that new evidence exists or was inspected**. Different reviewer statements change the visible explanation, but neither statement grants permission. A returned astronomy package requires a changed package plan and reference. Its curator can record only that capacity, inventory and integrity remain to be checked.

Oral history stops with community and privacy decisions outstanding. Neighbourhood interviews stop with the project consent owner and privacy office needing to read actual agreements. Brain images stop with a trained image reviewer and privacy office needing to inspect actual scans and companion fields. Coastal rare-site disclosure and genomic consent remain hard holds, with no curator action. No case grants access, publishes metadata or asserts handoff readiness.

The workbench uses `textContent`, not HTML interpolation, for authored and entered content. The state is in memory and Reset or refresh clears it. There is no upload, persistence or account. Hosts may log ordinary page requests. Neither a reference format check nor a fictional role switch authenticates a person or proves data safe.

## Verification

Run `python3 -m unittest discover -s tests -q`, `npm test`, `npm run test:browser` and `git diff --check`. Node tests cover six routes, negative choices, evidence gating, repair and hard holds. Playwright runs each route at desktop and mobile widths, review/package returns, focus, overflow and axe-core. These checks do not establish learner comprehension or cultural appropriateness; appointed reviewers and communities must assess those separately before operational use.
