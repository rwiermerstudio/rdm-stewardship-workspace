# Meridian learning role-play

This is a fictional teaching exercise, not an institutional review, consent process or repository service. Meridian's projects, people and candidate archives are invented.

## Learner route

Six cards name the discipline, researcher and situation before a choice. Each option includes a gain, cost and remaining uncertainty; the consequence is shown after selection. A compact process map keeps the relevant roles and stage statuses visible together, with their questions expandable. The initial workbench view hides the draft and copy labels. A risky choice alters the draft and event history without changing real files; Retry withdraws that proposal. The workbench generates sequential, unverified exercise-only evidence pointers for the proposed method and each correction. The learner never invents an identifier or enters subject content.

The steward, privacy reviewer and, for oral history, community-appointed reviewer select a case-specific statement about the draft or missing evidence. These are training responses, not inspection, consent or permission. Description visibility and recording requests are separate decisions. A reviewer can return a named missing check; a `needs-more` response left on record also remains an open question. The researcher chooses between a case-specific correction and an inadequate shortcut; the latter leaves review blocked. A correction generates a new pointer and appears alongside earlier pointers in the draft, but it does not prove the underlying evidence exists. The exercise offers one return-and-repair cycle per reviewer and one curator package return, then retains unresolved checks without presenting an unrepairable loop. This is a teaching limit, not a limit on real reviews. The astronomy curator can record only that capacity, inventory and integrity remain to be checked.

Oral history stops with community and privacy decisions outstanding. Neighbourhood interviews stop with the project consent owner and privacy office needing to read actual agreements. Brain images stop with a trained image reviewer and privacy office needing to inspect actual scans and companion fields. Coastal rare-site disclosure and genomic consent remain hard holds, with no curator action. No case grants access, publishes metadata or asserts handoff readiness.

The workbench uses `textContent`, not HTML interpolation, for authored content. The state is in memory and Reset or refresh clears it. There is no upload, persistence or account. Hosts may log ordinary page requests. A generated pointer is only an exercise label; a fictional role switch does not authenticate a person or prove data safe.

## Verification

Run `python3 -m unittest discover -s tests -q`, `npm test`, `npm run test:browser` and `git diff --check`. Node tests cover six routes, negative choices, evidence gating, repair and hard holds. Playwright runs each route at desktop and mobile widths, review/package returns, focus, overflow and axe-core. These checks do not establish learner comprehension or cultural appropriateness; appointed reviewers and communities must assess those separately before operational use.
